# ESP32-Smart-Refrigerator
The Smart Refrigerator is an IoT-based system designed to enhance food storage by monitoring environmental conditions and detecting food spoilage. It uses an ESP32 microcontroller as the central unit to process data from sensors and control the system efficiently.
